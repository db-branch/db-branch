# Support

db-branch is an independent open-source project maintained by one person. **No support is promised**: Issues are read when possible, with no response times.

Where to look first:

1. The [README](README.md) and the [documents in docs/](docs/README.md) (written in Japanese).
2. English user documentation: <https://db-branch.com/docs/getting-started/>
3. The live console demo: <https://demo.db-branch.com/>
4. Existing [Issues](https://github.com/db-branch/db-branch/issues), which may already answer your question.

If you found a bug, open an Issue using the bug report form and include your version, Ubuntu version, engine version and what you expected to happen. Feature ideas are welcome through the feature request form.

Security problems must not go in public Issues; see [SECURITY.md](SECURITY.md).
